# Juggling Class App

체육 수업용 저글링 성장기록 웹앱 v3입니다.

## 주요 기능

- 학생 정보 입력 및 로컬 저장
- 마음가짐과 저글링 활동지
- 회차별 기록 입력과 성장 그래프
- 최고·평균·최근 기록 및 성장 폭 표시
- 기록에 따라 올라가는 티어 시스템
- PWA 설치용 매니페스트와 서비스 워커

## Windows에서 실행하기

1. 저장소를 내려받아 압축을 풉니다.
2. `00_저글링앱_실행.cmd`를 실행합니다.
3. 브라우저가 열리지 않으면 `http://localhost:8765`에 접속합니다.

앱을 사용하는 동안 실행 창을 닫지 마세요. 학생 기록은 해당 브라우저에 저장됩니다.
